# Friday

> 会成长的个人助手 —— 把个人资料、邮件、办事大厅和手机连接起来，
> 让一次成功的尝试变成随时可用的能力，并在被纠正后越用越准。

## 实验目标

实现一个持续为你工作的个人助手，具备五项基础能力：

1. **个人数据库** —— 索引、检索个人资料，随资料变化更新索引，回答可定位到原文。
2. **持续关联 smail 邮箱** —— 获取新邮件、关联历史往来、生成回复草稿，去重处理。
3. **办理 ehall 事务** —— 查询信息并完成至少一种事务的材料准备与表单填写（保守、需确认）。
4. **手机端联动** —— 从手机发起任务、查看进度、编辑草稿、确认操作。
5. **能力组合** —— 各功能共享上下文，形成可反复使用的完整流程。

## 开发与协作

本项目使用 Git 管理实现和规则。成功流程、纠正记录、脚本与技能都应可阅读、可修改，并纳入版本控制。

```bash
git add .
git commit -m "描述你的改动"
git push
```

### 安全提醒

个人助手项目会接触邮箱、办事账号等敏感信息。**切勿提交任何密钥、令牌或个人隐私数据**，
相关文件已默认写入 `.gitignore`。
